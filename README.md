## install
either:
* download `0.theme.css` and drop it into your vencord themes folder *(preferred)*
* copy [this link](https://raw.githubusercontent.com/zoe2276/vc-theme0/refs/heads/main/0.theme.css) and paste into your remote themes block

it will automatically update with any changes to this repository. 

## config
`0.theme.css` has variables within that are lightly commented for explanations. there are additional configs at the bottom for specific cases, such as sending messages. be sure to update where specified so it works as expected.
